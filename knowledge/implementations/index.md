# implementations

- [Chez Scheme](/implementations/chez.md) - Fast-compiling native Scheme with a category-level type lattice, automatic unsafe promotion, and no classical loop optimizer.
- [SBCL](/implementations/sbcl.md) - Common Lisp implementation with interval and relational constraint propagation, SIMD intrinsics, and no autovectorizer.
- [Stalin](/implementations/stalin.md) - Whole-program optimizing Scheme compiler. C-competitive on numeric code, catastrophic on allocation-heavy code.
